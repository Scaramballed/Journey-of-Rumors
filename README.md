# Journey of Rumors

A text-based RPG built in Python while learning object-oriented programming.

---

## About

This is a terminal-based game where the player manages health and craving stats while exploring different areas. The project was built as a learning exercise to practice Python, OOP, and game state management.

---

## Features

- Health and craving system
- Mom's Room with dialogue choices
- Dungeon levels with math puzzles
- Study system with typing challenges
- Multiple endings based on player stats
